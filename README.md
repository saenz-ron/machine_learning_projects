### Project 1: Gradient Descent
This script uses gradient descent to find the minimum for the function f(x,y,z) = x^2+y^2+z^2-x-y+z. In addition, the script also displays a curve that illustrates the change of the values of (x, y, z) between two consecutive iterations changes with respect to the iteration number.
